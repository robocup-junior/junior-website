{{< wp-intro >}}*How RoboCupJunior compares with other student robotics programs*{{< /wp-intro >}}

{{< wp-prose >}}
There are many great robotics competitions for school students, and the best one for your team depends on what you want to learn. This article compares RoboCupJunior (RCJ) with three other large international programs: **FIRST**, **VEX Robotics** and the **World Robot Olympiad (WRO)**. It covers how each program works, what robots and hardware you can use, and the programming skills each one builds.

Many students take part in more than one program, and the skills carry over. Plenty of RoboCupJunior teams started with a kit-based competition and moved on to RCJ’s open challenges.

New to RoboCupJunior? Read [How to Get Started](/gettingstarted/) first.

## What Makes RoboCupJunior Different
{{< /wp-prose >}}

{{< gs-cards cols="2" >}}
- **Fully autonomous, all the time.** There are no joysticks and no driver-controlled periods. Once a game or run starts, the robot senses, decides and acts on its own.
- **Any platform.** Teams can use the kits they already have, then move on to microcontrollers, custom electronics and 3D-printed parts. There is no required kit or supplier.
- **Challenges that build year on year.** Leagues keep the same core challenge and the rules change step by step, so teams improve their robot instead of rebuilding from scratch, and fields can be reused.
- **Small teams, hands-on roles.** Teams have 2 to 4 students (up to 5 in OnStage), so every student works on the robot and explains their part to the judges.
{{< /gs-cards >}}

{{< gs-callout title="Check the details with each program" >}}
Every program updates its rules, divisions and fees each season, and they can vary from region to region. We checked these comparisons against each program’s own information in **November 2026**. Always confirm the details with each program before you decide.
{{< /gs-callout >}}

## Robots and Hardware
{{< /wp-prose >}}

<div class="gs-compare">

{{< wp-table >}}
| | RoboCupJunior | FIRST | VEX Robotics | World Robot Olympiad |
| --- | --- | --- | --- | --- |
| **How robots are controlled** | Fully autonomous in every league | FIRST LEGO League robots are autonomous. FTC and FRC matches have a short autonomous period followed by driver control. | Mostly driver-controlled, with autonomous periods and skills runs. VEX AI is fully autonomous. | Fully autonomous in most categories |
| **Hardware** | Any kit, controller, sensors and parts, within the size, weight and safety rules | Set control systems and approved parts for each program; FIRST LEGO League uses LEGO Education robotics sets | VEX parts and electronics, with limited exceptions | LEGO-based robots in RoboMission; open hardware in Future Engineers and Future Innovators |
| **Robot size** | Small: most robots fit within roughly 22 to 25 cm, depending on the league | Ranges from small LEGO robots up to FRC robots more than 1 metre tall | Small to medium, set by each game | Small LEGO robots in RoboMission; set by each category elsewhere |
| **Year to year** | Gradual rule changes, so teams can keep improving the same robot and reuse their practice fields | A new game each season, so most teams build a new robot | A new game each season, so most teams rebuild | New challenges each season, with surprise rules announced on the competition day |
| **Cost** | Depends on the platform you choose. Teams can start with kits they already own; see [Starting a Team](/robocup-beginners-guide/#costs) | Varies by program; FRC is the most resource-intensive and usually needs fundraising | Depends on the VEX parts needed for each game | Depends on the category; LEGO-based categories need a LEGO robotics set |

## Programming and Skills
{{< /wp-prose >}}

<div class="gs-compare">

{{< wp-table >}}
| | RoboCupJunior | FIRST | VEX Robotics | World Robot Olympiad |
| --- | --- | --- | --- | --- |
| **Programming languages** | Any language and tools the team chooses | Block-based programming in FIRST LEGO League; Java and other text languages in FTC and FRC | VEXcode (blocks, Python and C++) and other supported tools | Any language that runs on the allowed controllers |
| **Software focus** | Sensing, decision-making and control for the whole game; many teams use computer vision, and some use machine learning | Strong focus on mechanical design and driving, with software for the autonomous period | Strong focus on mechanical design and driving, with software for autonomous runs; heavier software in VEX AI | Precise autonomous navigation and task completion; computer vision in Future Engineers |
| **Simulation option** | Yes: Rescue Simulation, programmed in the Erebus simulator, with no robot hardware needed | No | Virtual skills challenges using VEXcode VR | No |
| **Judging and presentations** | Technical interviews in every league, plus posters or documentation | Judged awards, engineering portfolios and a project presentation in FIRST LEGO League | Judged awards and engineering notebooks | Project presentations in Future Innovators and Future Engineers |

## Which Program Suits Your Team?
{{< /wp-prose >}}

{{< gs-cards cols="2" >}}
- **RoboCupJunior may suit you if** your team wants to program robots that think for themselves, use the hardware you choose, keep improving the same robot over several seasons, and take part in an international community run by volunteers.
- **A kit-based program may suit you if** your team wants a set kit to start with, a new game to build for each season, or driver-controlled matches. Many students learn the basics this way, then take on RoboCupJunior’s open challenges.
{{< /gs-cards >}}
