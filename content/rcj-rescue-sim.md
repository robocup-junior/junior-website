{{< league-intro tagline="Come prepared to be the most successful rescue team." >}}
**RCJ Rescue Simulation (Webots-Erebus)** brings exciting new learning opportunities on a newly developed platform, Webots-Erebus. The virtual robot explores and maps a maze with different rooms and identifies victims on its way.
{{< /league-intro >}}

{{< league-facts label="Rescue Simulation at a glance" >}}
{{< league-fact label="Platform" >}}**Webots-Erebus** simulator{{< /league-fact >}}
{{< league-fact label="Robot" >}}A virtual robot with an autonomous controller{{< /league-fact >}}
{{< league-fact label="Goal" >}}Explore and map the maze and identify victims{{< /league-fact >}}
{{< league-fact label="Rules" >}}Like Rescue Maze, plus harder terrain and elements of RoboCup Rescue Major{{< /league-fact >}}
{{< /league-facts >}}

{{< league-section title="About the challenge" >}}
{{< league-media image="/wp-content/uploads/2026/01/Robocup-1081-683x1024.jpg" alt="A large screen showing a Rescue Simulation maze run" >}}
The rule set for RCJ Rescue Simulation is similar to RCJ Rescue Maze, extended with new areas of more difficult terrain. Some elements from RoboCup Rescue Major are also incorporated.

<p class="lg-quote">Rescue teams can use robots to search complicated, dangerous or hard-to-access environments, minimising the risk to humans.</p>

{{< league-more summary="Read the full scenario" >}}
*In this challenge, the autonomous controller for a robot must be developed to search and identify wall tokens, recognising the environment in a simulated hazardous rescue scenario. The robot must navigate through challenging terrain without getting stuck, search for wall tokens, and signal the wall tokens' locations alongside the map of the maze environment to human search teams.*
{{< /league-more >}}
